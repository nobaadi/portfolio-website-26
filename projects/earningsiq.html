RAG Architecture
// How EarningsIQ turns a document into a grounded answer
01
Chunk
500-token windows with 80-token overlap preserving context across chunk boundaries
->
02
Index
TF-IDF matrix built in-memory. IDF weights penalise common financial boilerplate
->
03
Retrieve
Cosine similarity scoring. Top-4 passages returned and shown to you with relevance scores
->
04
Generate
Claude answers using ONLY retrieved passages. No hallucination, grounded in your document
Why show you the retrieved passages? Transparency is the point. Unlike a black-box chatbot, EarningsIQ shows you exactly which parts of the document it used to generate the answer, so you can verify it yourself. If no passage scores highly, it tells you that too.
